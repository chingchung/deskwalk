# 吐糟王 (Roast King) — SoulQuest prototype 02

一個「**掃 QR → 自動派牌 → 傾偈途中塞吐槽**」嘅派對遊戲原型。
全靜態網頁，可以直接擺上 GitHub Pages，唔使任何 server。

> SoulQuest 設計專案嘅每週小原型。

---

## 玩法（呢版冇計分）

吐槽由「甩單字」變成「**整句吐槽塞入對話**」——配上唔計分，佢就由比賽變成
**祕密任務 / 吐槽 bingo**：你手上 5 句係呢鋪嘅 mission，成功喺傾偈途中自然講出口
就撳「完成」。**全場反應就係裁判**，唔需要分數。

1. **主持出題**　主持部機（或者投上電視）show 住一條題目同一個 QR code。
2. **掃描入場**　大家用手機 scan，網頁會自動派 **5 句吐槽 + 當前題目**。
3. **塞入對話**　傾呢條題目嘅時候，搵窿將你嘅吐槽講出嚟。
4. **撳完成**　講得出 → 撳一下點選、**再撳一下確認**（雙重確認防誤觸），畫面打個「搞掂 ✓」。
5. 五句全部出晒 = 呢鋪嘅吐糟王。想再玩就「換 5 句」。

主持自己都想玩？撳「**我都要玩**」用按鍵入場，唔使 scan。

---

## ⚠️ 一個你要知嘅限制（靜態網頁嘅誠實話）

冇 server，所以 **題目係喺你 scan 嗰一刻鎖入 QR code 入面**。

- 主持撳「下一題」→ QR 會更新，**之後先 scan 嗰啲人**會攞到新題目。
- **已經 join 咗嘅手機唔會自動跳題**——要轉題，叫佢哋 re-scan 一次，或者望主持機 / 大電視。

呢個係靜態 host 嘅天生限制。要做到「主持一撳全場手機即時跳題」嘅真・即時同步，
要加 backend（例如 Firebase / Supabase）。對於「一條題目傾耐啲」嘅玩法，現版已經夠用。

## 玩 / 部署

**要 scan 到，一定要先 deploy**（file:// 喺別人部機開唔到）。

1. push 上 GitHub（見下）
2. Repo → **Settings → Pages → Source 揀 `main` branch / root**
3. 網址會係 `https://<你帳號>.github.io/<repo名>/`，主持開呢條 URL 就見到 QR。

**本機測試**（唔使 deploy）：直接開 `index.html` 係主持台；
想睇玩家畫面，開 `index.html?play&t=0`（`t` 係題目編號）。

## 換你自己嘅牌組 ★

打開 `index.html`，最上面 `<script>` 有兩個 array（已標「牌組喺呢度改」）：

```js
const TOPICS = [ "講一件你做過、而家諗返都想 plz del 嘅事", ... ];

const LINES = [
  ["Siu4，你講真定講笑？", "有人講咗啲離譜嘢"],   // [吐槽句, 出牌時機提示]
  ...
];
```

- **TOPICS**：用嚟引人傾 / 嗌交 / 自爆嘅題目（越多磨擦越多吐槽位）。
- **LINES**：整句吐槽，內置 2025 香港 Threads / 連登潮語 + 經典 viral 金句（已避粗口同政治）。
  想換口味、加你 friend group 嘅 in-joke，直接改。

呢度先係呢隻 game 真正嘅內容設計。
