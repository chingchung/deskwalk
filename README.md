# deskwalk

桌遊設計專案。Work in progress。

## 定位

小品 / 對話 / 默契 / 派對向，**不是策略型**。低門檻、好上手、揭曉瞬間有社交高潮。

## 設計原則

1. **機制 > 內容。** 市面上對話卡牌已經一大堆，光有好題目無法突圍。能突圍的是一個「好玩到想一直玩」的機制。內容是彈藥，機制是槍。
2. **保持開放。** 在找到真正有趣的機制之前不收斂、不綁死單一產品。大方向不變（小品/派對），但機制隨時可加可砍。
3. **以「好玩的時刻」評估。** 判斷一個機制好不好，問的是「它製造了什麼讓人忍不住叫出來的瞬間」，而不是「它合不合某個產品」。

### 品牌與視覺系統

所有原型共用同一套輕量、簡潔的視覺語言，讓整個系列看起來像出自同一品牌：

- **`brand.css`** — 唯一的設計基底（design tokens + 共用元件）。各原型 `<link>` 引用，確保一致。
- **暖紙格底 + 流動光暈**（warm graph-paper）— 呼應「deskwalk」桌面感的招牌底紋，後方有極淡、會緩慢飄移的暖橘／藍／綠光暈，給玻璃折射用。
- **Apple 液態玻璃面材**（liquid glass）— 所有卡片／面板都是半透明霜面玻璃：背景模糊（`backdrop-filter`）＋ 1px 高光鑲邊（inset specular rim）＋ 軟陰影。保持輕、柔、通透，不是深色 glassmorphism。
- **單一品牌色**：暖橘 `--accent: #F0522E`，主要按鈕用漸層玻璃 CTA，重點與品牌標記統一使用；深色面板用 `--card-ink` 暗玻璃。
- **deskwalk 系列標記** — 每個原型角落都有可回到首頁的 `deskwalk` 玻璃標，串起整個系列。

> 各遊戲僅在「內容色」上保留少許個性（如 1234 的四色數字、集體潛意識的 Yes/No・形狀・難度色），介面外框一律統一。
