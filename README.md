# deskwalk

桌遊設計專案。Work in progress。

## 定位

小品 / 對話 / 默契 / 派對向，**不是策略型**。低門檻、好上手、揭曉瞬間有社交高潮。

## 設計原則

1. **機制 > 內容。** 市面上對話卡牌已經一大堆，光有好題目無法突圍。能突圍的是一個「好玩到想一直玩」的機制。內容是彈藥，機制是槍。
2. **保持開放。** 在找到真正有趣的機制之前不收斂、不綁死單一產品。大方向不變（小品/派對），但機制隨時可加可砍。
3. **以「好玩的時刻」評估。** 判斷一個機制好不好，問的是「它製造了什麼讓人忍不住叫出來的瞬間」，而不是「它合不合某個產品」。
